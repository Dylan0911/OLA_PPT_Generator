# 弥撒PPT生成

本工具在本机运行，不需要服务器。网页只使用一个最终模板：

`assets/OLA_Liturgy_Final_Template.pptx`

## 使用

1. 在 Terminal 里进入本文件夹。
2. 运行：

```bash
npm start
```

3. 浏览器打开：

```text
http://127.0.0.1:4177
```

4. 上传 `.docx`、`.txt` 或 `.md` 文档，生成后下载 PPT。

网页上的“下载最终模板”会下载同一个模板文件。

## 当前支持

文档中已包含以下这些部分，会自动对应到 PPT 相应位置：

`集祷经`、`读经一`、`答唱咏`、`读经二`、`福音前欢呼词`、`福音`、`信经`、`信友祷文`、`献礼经`、`领圣体后经`、`隆重降福`。

这些页面会保留红字占位，生成后人工填写：

`进堂咏`、`奉献咏`、`领主咏`、`礼成咏`、`堂区报告`。
